# SPA-P Matching website

## Setup (Windows, from this folder)
    pip install -r requirements.txt
    uvicorn main:app --reload
Then open http://127.0.0.1:8000

Needs `g++` on PATH (you already have it). `algo.cpp` is compiled automatically on first run.
Upload a `data.txt` in the same format as before, or click "Run sample data".
